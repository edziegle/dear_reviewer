# Review keys

Every review key is Ctrl+Alt+R, then a letter. On a Mac, press ⌃⌥R in place of Ctrl+Alt+R.

## Read the Change

| Key | Command |
| --- | --- |
| Ctrl+Alt+R N | Next Unviewed File |
| Ctrl+Alt+R P | Previous Unviewed File |
| Ctrl+Alt+R V | Mark Viewed and Open Next |
| Ctrl+Alt+R D | Open All Diffs |
| Ctrl+Alt+R C | Show Changes Since Your Last Review |

## Understand it

| Key | Command |
| --- | --- |
| Ctrl+Alt+R G | Show Code Flow |
| Ctrl+Alt+R A | Ask the Assistant |
| Ctrl+Alt+R I | Ask for Findings |
| Ctrl+Alt+R F | Next Finding |
| Ctrl+Alt+R Shift+F | Previous Finding |

## Move and finish

| Key | Command |
| --- | --- |
| Ctrl+Alt+R O | Show Overview |
| Ctrl+Alt+R H | Show Dashboard, in the window you work in |
| Ctrl+Alt+R S | Submit Review… or Write Brief… |
